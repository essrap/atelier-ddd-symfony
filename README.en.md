# Atelier DDD Symfony

*[Version française](README.md)*

Companion repository for the video series **"DDD, CQRS, SOLID and design patterns with Symfony"** (videos in French, with an English audio track).

It builds **Tooloc**, an equipment rental back end between individuals and professionals: owners list equipment, renters book it for a time slot.

## Layout

- `projet/`: the full Symfony application, built episode by episode.
- `exemples/`: isolated code (often before / after) for principles that are easier to show outside the project.

Each episode matches an `ep-NN` tag: you can pick up the series at any episode.

## Status

Work in progress: the quality foundation comes with episode 1.
