# Atelier DDD Symfony

*[English version](README.en.md)*

Dépôt d'accompagnement de la série vidéo **« DDD, CQRS, SOLID et design patterns avec Symfony »**.

On y construit **Tooloc**, un back-end de location de matériel entre particuliers et professionnels : des loueurs publient du matériel, des locataires le réservent sur un créneau.

## Organisation

- `projet/` : l'application Symfony complète, construite épisode par épisode.
- `exemples/` : du code isolé (souvent avant / après) pour les principes qui se montrent mieux hors du projet.

Chaque épisode correspond à un tag `ep-NN` : tu peux reprendre la série à n'importe quel épisode.

## État

En construction : le socle qualité arrive avec l'épisode 1.
